# ✠ نظام حضور وغياب وتقارير اجتماع إعدادي ✠

موقع ويب متكامل وحديث مخصص لاجتماعات المرحلة الإعدادية بالكنيسة لمتابعة وتسجيل حضور الطلاب والأنشطة الروحية الأسبوعية، مع نظام تقارير ذكي يحسب عدد المرات التي حضرها كل طالب تلقائياً من أصل عدد الفعاليات التي أقيمت في أي فترة تختارها، وتصدير التقارير إلى مستند **Microsoft Word (.docx)** منسق وجاهز للطباعة.

---

## ✨ المميزات الرئيسية للموقع

1. **تقسيم الطلاب حسب المرحلة (القسم)**:
   - **سنة أولى إعدادي**
   - **سنة ثانية إعدادي**
   - **سنة ثالثة إعدادي**
   - عند إضافة أي طالب يتم تحديد قسمه فوراً.
   - إمكانية التصفية بحسب القسم في شاشة تسجيل الحضور اليومي أو في شاشة التقارير أو في إدارة الطلاب.

2. **الأنشطة الأسبوعية والبنود المقررة (الذكاء التلقائي في تحديد اليوم)**:
   - **يوم الثلاثاء**: حضور الاجتماع
   - **يوم الأحد**: صلاة الأجبية + السلوك + الكتاب المقدس
   - **يوم الخميس**: التسبحة
   - **يوم الجمعة**: القداس الإلهي
   - *اقتراح ذكي*: بمجرد اختيار التاريخ يقوم الموقع تلقائياً باقتراح وتفعيل البنود المناسبة لليوم مع إمكانية التعديل وتفعيل أي بند آخر بحرية تامة.

3. **تسجيل الحضور بالاسم بسهولة فائقة**:
   - حقل بحث سريع لتسجيل حضور أي طالب فوراً بمجرد كتابة أول حرفين من اسمه.
   - أزرار سريعة بنقرة واحدة (حاضر / غائب) بألوان واضحة ومريحة للعين.
   - أزرار تحضير الكل أو إلغاء الكل بنقرة واحدة.

4. **نظام التقارير الذكي والحساب التلقائي**:
   - اختيار الفترة الزمنية: من تاريخ [....] إلى تاريخ [....].
   - اختيار القسم: (جميع المراحل، سنة أولى إعدادي، سنة ثانية إعدادي، سنة ثالثة إعدادي).
   - **الحساب التلقائي الدقيق**:
     * كم مرة أقيم الاجتماع في هذه الفترة؟
     * كم مرة أقيمت صلاة الأجبية والسلوك والكتاب المقدس والتسبحة والقداس؟
     * لكل طالب: كم مرة حضر من أصل كم مرة أقيمت الفعالية؟ (مثال: حضر 4 من أصل 4 في الاجتماع، 3 من أصل 4 في القداس).
     * حساب المجموع الكلي للحضور من إجمالي الفرص المتاحة وحساب النسبة المئوية الدقيقة (%).
     * تقييم تلقائي لكل طالب (ممتاز 🌟 / جيد جداً 👍 / جيد 👏 / يحتاج متابعة ⚠️).

5. **تصدير التقرير إلى مستند Word (.docx)**:
   - تصدير ملف Microsoft Word حقيقي (.docx) بضغطة زر واحدة.
   - ترويسة كنسية أنيقة باللغة العربية (RTL).
   - جدول ملون وشامل لكل الطلاب وإحصائيات كل بند.
   - خانات توقيع خادم المرحلة وأمين الخدمة وكاهن الاجتماع.
   - خيارات إضافية: طباعة مباشرة منسقة للورق (A4 / PDF) وتصدير كملف Excel (CSV).

6. **حفظ البيانات والأمان الكامل**:
   - حفظ تلقائي فوري في المتصفح.
   - إمكانية تنزيل نسخة احتياطية (ملف JSON) لنقل البيانات لأي جهاز أو موبايل آخر.
   - إمكانية استيراد النسخة الاحتياطية واستعادة البيانات في أي وقت.
   - بيانات تجريبية جاهزة لتجربة الموقع فوراً والاطلاع على التقارير بضغطة زر.

## 🚀 طرق تشغيل الموقع

### الطريقة الأولى (الأسهل والأسرع):
اضغط مرتين (Double Click) على الملف:
```
start.bat
```
سيقوم بفتح الموقع مباشرة في متصفحك الافتراضي (Google Chrome / Microsoft Edge).

### الطريقة الثانية:
يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح، وسيعمل الموقع بكامل وظائفه حتى بدون إنترنت!

### الطريقة الثالثة (عبر السيرفر المحلي):
افتح موجه الأوامر (Terminal / CMD) في مجلد المشروع واكتب:
```bash
npm start
```
أو:
```bash
node server.js
```
وسيفتح الموقع على الرابط: `http://localhost:3000`
